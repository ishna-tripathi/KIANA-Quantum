# KIANA Quantum Website

## Files

- `index.html` — main website
- `styles.css` — complete styling
- `script.js` — small interactions
- `hero-banner.png` — supplied KIANA Quantum banner used as the hero background

## GitHub Pages

Upload all four files to the root of the GitHub repository.

The site is designed to work as a static GitHub Pages website.

## LinkedIn jobs

The "View Jobs" buttons link directly to the KIANA Quantum LinkedIn company page.
