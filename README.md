# KIANA Quantum — Website

A static, responsive GitHub Pages website for **KIANA Quantum Limited**, positioned as an IT consultancy rather than a quantum/science company.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling and visual system
- `script.js` — mobile navigation
- `README.md` — deployment notes

## Run locally
Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `kianaquantum.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. In **Settings → Pages**, choose **Deploy from a branch** and select `main` / root.
4. Your site will be available on the GitHub Pages URL.
5. Later, connect `kianaquantum.com` through GitHub Pages' **Custom domain** setting.

## Before launch
- Replace `hello@kianaquantum.com` with the real enquiry address if different.
- Add the final company registration details in the footer if required.
- Replace the CSS-built K mark with the final brand SVG/PNG if you want the exact logo artwork.
- Add real case studies, client logos, team information and legal/privacy pages as the business grows.

## Design direction
The site takes inspiration from the supplied Dublin AI Week page: large editorial typography, dark high-contrast sections, numbered service blocks, clear scroll rhythm, and strong calls to action — but uses an original KIANA Quantum IT-consultancy identity.
